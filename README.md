# Mindful-U – Thiết kế UI/UX

Ứng dụng di động hỗ trợ chăm sóc sức khỏe tinh thần cho sinh viên thông qua thiền, theo dõi tâm trạng và âm thanh thư giãn.

## Tổng quan dự án
- Nghiên cứu và phân tích nhu cầu người dùng
- Xây dựng Persona, User Flow và Wireframe
- Thiết kế giao diện và Style Guide trên Figma
