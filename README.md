# Mindful-U – UI/UX Design

Mobile app concept designed to support students' mental wellness through meditation, mood tracking, and relaxing audio.

## Project Overview
- Conducted user research and analyzed user needs
- Developed Persona, User Flow, and Wireframe
- Designed UI screens and Style Guide in Figma
